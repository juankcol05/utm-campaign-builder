# UTM Campaign Builder

Aplicación web estática para generar URLs con parámetros UTM y llevar un histórico local.

## Funciones

- Generación de utm_source, utm_medium, utm_campaign, utm_term y utm_content
- Normalización automática a minúsculas y guiones bajos
- Copiar URL generada
- Histórico local en el navegador
- Dashboard de UTMs generadas
- Exportación CSV
- Diseño responsive

## Nota

Esta versión mide las UTMs creadas dentro de la herramienta. Para medir sesiones, leads, conversiones, revenue y ROAS, la siguiente evolución debe conectarse con GA4 u otra fuente de analítica.
